PLC & HMI Developer

The screen is where the machine gets understood.

I build the operator side of industrial control systems — winches, carriages, mobile hydraulics. The machine already knows what is wrong. Whether the operator knows depends entirely on how the screen says it: a crowded interface turns a five-minute fault into a stopped machine, a clear one does the opposite. That is design work, and it is not decoration.
